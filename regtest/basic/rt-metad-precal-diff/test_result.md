## PRECAL_DIFF Test Results (OU Trajectory)

### Setup
- **Source**: `run_precal_suite.sh`
- **Trajectory**: Ornstein-Uhlenbeck process generated by `generate_trajectory.py`
  - Parameters: dt = 0.005 ps, τ = 0.5 ps, σ = 0.15 nm
- **MetaD Configuration**: 
  - ADAPTIVE=DIFF, PRECAL_DIFF toggled ON/OFF
  - PACE=5, TEMP=300, BIASFACTOR=5, SIGMA=4000 (20 ps)
- **UPDATE_FROM Values**: 0, 0.25, 0.5, 1, 2, 4, 5, 10, 20, 40 ps
- **Reproduction**: `./run_precal_suite.sh | tee test_output`

### Key Observations

1. **Validation at UPDATE_FROM=0**: Identical behavior with/without PRECAL_DIFF confirms correct implementation
2. **Systematic Enhancement**: PRECAL_DIFF consistently produces larger first-hill sigma values, addressing early-time underestimation in ADAPTIVE=DIFF
3. **Scaling with UPDATE_FROM**: As UPDATE_FROM increases, ON_sigma approaches values more representative of the true OU process width (σ = 0.15 nm)
4. **Physical Interpretation**: Pre-averaging from t=0 effectively mitigates small-sigma artifacts that occur when hills are deposited before sufficient sampling

### Implementation Files
- **`run_precal_suite.sh`**: Main test script that generates inputs, executes OFF/ON comparisons, and produces summary statistics
- **`test_output`**: Console output containing the tabulated results
- **`generate_trajectory.py`**: OU trajectory generator for consistent test conditions
